## Feras's additions (11-02, second batch) and where they land
1. Diagram: agreed (scripts as foremen; one Haiku-low flag confirmer; Sonnet subagents allowed at high, decision logged).
2. **Mechanical lane** (S11): work needing no reasoning goes to DeepSeek non-reasoning (`cf_build.sh ... fast`, ~1200 output tokens/s). Constrained by construction: a mechanical brief is a literal edit list (file, anchor text, exact replacement; no "improve"), May edit = only those files, a locked test or a grep assertion per edit, Pattern file pasted, and the gate rejects any file outside May edit. The head decides where to use it, writes the exact instructions and tests it: first use is one smoke edit on a trivial change, then it is judged by diff-equals-spec (a script compares the diff to the edit list), not by trust. Fix passes of a fast build go to the max model (already so).
3. **No context pollution** (S10 + skill rule): the head reads at most 15 lines per part (`part_report.py`), redirects every long command to a file and reads offsets, never cats a log or diff, and tools print short results by default (the run output files are never pasted). Seen this session: one test run echoed 100 KB into the chat. Rule: run noisy commands as `cmd > file; tail -n 15 file`.
