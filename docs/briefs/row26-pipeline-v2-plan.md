- Rejected from the critics: "first build has no timeout" (oc_task.sh caps it at OC_TIMEOUT 90m); "merge takes unreviewed commits" (those are the head's own fixes, by design); "MAP.md hidden from review" (generated, check.sh enforces it); DS "blocker: builder scripts run before the gate" (the gate BREACHes any edit to tools/ unless May edit lists it, and a builder has a shell anyway: the boundary is the worktree and the gate; noted, not a blocker); CI wait is not a bug today (5.5 min runs, one workflow) but is a latent one.
