## What to build
`tools/doc_graph.py`, <= 200 lines, every function <= 40 lines, a `##`-free docstring first, `--root DIR` (default the repo) so tests run on toy repos.
1. Nodes: every tracked-looking `*.md` under the root except `docs/archive/`, `docs/research/`, `inbox/`, `assets/`, `.godot/`, `.check/`, `.claude/worktrees/`, and `docs/DOCMAP.md` itself. Purpose = the front-matter `description:` if present, else the first non-empty line that is not a heading marker only (strip leading `#`).
2. Edges: inside a node, every token that looks like a repo path (`[A-Za-z0-9_./-]+` with a `/` and an extension in md, py, sh, gd, json, csv, tscn, tres, cfg, conf, yml, or ending in `/`) and every `@file.md` import. A token resolves when it exists relative to the root, or relative to the node's own folder. Tokens containing `*`, `<`, `>`, `{`, `$`, `..`, `http` or a space are ignored. Code files are not nodes but their existence resolves a reference.
3. Dangling = a reference that does not resolve and is not in the allowlist file `docs/doc_graph_allow.txt` (one `node-path :: token` per line, `#` comments). Orphan = a node with no inbound edge from another node, unless it is CLAUDE.md, HANDOFF.md, README.md, docs/MAP.md, a `SKILL.md`, an agent file under `agents/`, or `docs/DOCMAP.md`. Overlap = a normalized (lowercase, whitespace collapsed) line of >= 80 characters, outside tables of contents and code fences, that occurs in two or more different nodes.
4. Default run writes `docs/DOCMAP.md` (header "generated by tools/doc_graph.py; do not edit by hand", then a table `path | purpose | in | out`, then sections Dangling, Orphans, Overlaps, each sorted; byte-identical on a second run). Exit 0.
5. `--check`: exit 1 and print one line per problem when DOCMAP.md is stale, or a dangling reference is not in the allowlist; orphans and overlaps print as `WARN` and do not fail.
6. `--baseline`: write the current dangling references into the allowlist (sorted) so a ratchet starts from today.
7. `--who-mentions TERM`: print `path:line: text` for every line containing TERM in the nodes and in `.py .sh .gd .json .conf .csv` files under tools/, plugins/, .claude/, features/ and core/ (skip .godot, .check, worktrees); exit 0 with matches, 1 with none.
8. Wire into `tools/check.sh`'s docs step: after `doc_check.py` runs, run `python tools/doc_graph.py --check` and fail the step on exit 1 (read how doc_check is wired and do the same). Then run `--baseline` once and `python tools/doc_graph.py` to commit `docs/doc_graph_allow.txt` and `docs/DOCMAP.md` as they are today.
