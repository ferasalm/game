FAIL (repro: two loops in parallel 5/10 red; alone 0/24, under 8-core CPU load 0/12; a monitor saw 29 pings, none

## Lessons for P3 (LESSONS is at its cap)
- msys exec of an msys program = a new Windows process whose parent (the fork) exits: Windows-tree kills miss it; freeze
  the tree before killing, and join msys `ps` (PID, PPID, WINPID) to the Windows snapshot.
- A test that counts processes by name machine-wide is flaky with parallel checkouts: mark the test's children.
- A `\\n` in a Python heredoc via the Bash tool arrives as a newline again (LESSONS 4): use Edit for such strings.
