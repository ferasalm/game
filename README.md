# Neon Glitch

A 2D isometric action RPG with real-time, Hades-like combat and a linear story, set in a cyberpunk Old Sana'a. Made
with Godot 4.7.2. Status: before M1, the first playable real-time fight (docs/VISION.md, roadmap).

- **Play the current build:** install Godot 4.7.2 (Standard), open `project.godot`, press F5 (features/neon/neon_game.tscn).
- **Vision and roadmap:** docs/VISION.md; the canon (story, art, combat): docs/CANON.md
- **How it's built:** docs/ARCHITECTURE.md; code map: docs/MAP.md; how the studio works: docs/WORKFLOW.md
- **Run every check:** `tools/check.sh`
